# M2a 백로그·미결 사항 (2026-09-05, 브랜치 통합 시점)

M2a(시트 판독 → 계열 통합 → 적대적 검토 → DB → 크롭)는 `feat/m2a-reading`(15커밋, 277 tests)로 구현·검토 완료.
합격 판정·시범 자료는 `data/derived/ab1-p4p5/{pilot-report,acceptance}.md`(gitignore, 로컬 보관).

## 1. 사용자 결정 보류 — 데이터 재실행 (실호출·과금, 크레딧 ≈$6.3)
- 시트 판독 캐시 61건 중 **14건**이 용지 밖 `mm_bbox`(A02p1·A04p1·A05p1·C01p1·C13p1·C14p1·C22p1·C23p1·C25p1·D01p2·D07p1·D07p2·E02p1). 최종 픽스(6787104)로 시트 단계 재검증이 생겨 지금은 `read/review --cache-only` 가 이 시트에서 `CacheMissError` → `scripts/verify-m2a.ps1` 3·4단계 red(과금 없음).
- 선택지: 최소 A·D(6페이지 재판독 + A·D 통합·검토 ≈$2.7) / 전체(14페이지 + A·C·D·E 통합·검토 ≈$5.5). 크레딧 충전 후 실행.
- Q4(A04 면진받침 방향) 미검출: (a) `REGION_HINTS["A"]` 에 "받침배치표는 교각 열마다 개별 항목" 추가 → A 계열 재과금 ≈$1.6 (b) 계열 간 상충은 LLM 없는 결정론 후처리(P\d+ 받침 토큰 횡단 비교 → ambiguity 자동 생성)로 M2b 전 처리 권장.
- F 계열 검토 지적 1건 잔여("P1 받침 NO.1 종류" — reading item 이 target 보다 구체적): 수동 하향 또는 매칭 규칙 확장.

## 2. 코드 백로그 (최종 검토 triage: 백로그)
- `read_sheet` 가 캐시 히트 판정 전에 이미지 전처리(리사이즈·크롭·sha 3회)를 매번 수행 — 대량 재실행 I/O.
- `call_structured`: `stop_reason=max_tokens` 이면 post_validate 위반 목록이 재시도 문구에 실리지 않음; 스키마 stale 캐시는 미스가 아니라 예외.
- read `MAX_TOKENS=8000` 은 고밀도 시트(C04·D02·D04·D07·F01)에서 절단 → 상향은 캐시 키에 포함돼 전량 재과금이므로 전면 재실행 시점에만.
- `review --help` 문구(캐시 미스면 과금), `--budget-usd` 누적 상한, usage.jsonl cached 행 누적, `_pages_map` 중복 I/O, `has_review_rows` 계열마다 새 커넥션, `_save_review` 초 단위 백업 스탬프, `failed` 카운터 r/a 미구분, `failed_regions` 첫 글자 판정, `_tokens` 조사 구분자(단어 경계 없음), `db.TABLES` 에 readings/ambiguities 미포함, `store` crosscheck `{expr}` 만 저장(설계 §5 `{expr,result,ok}` 와 불일치), 테스트 `_env` 픽스처가 실제 `.env` 로드(delenv 가드 권장), 상수 복제 단언 테스트 2건.
- 설계 미기록 편차: 표제란 타일 1장(설계 §4-1 2~3장), 회전 도곽 미지원(rot=0 전제), 온도 미적용(Sonnet 5 sampling 400), 녹화 응답 픽스처 대신 수기 JSON.
- 크롭 A/C/D/E/F 51장 육안 미확인(B 8장 + 2장만 확인).

## 3. M2b 설계 메모
- `decisions.ambiguity_id` FK: `replace_region` 이 delete+insert(자연키 일치 시 id 보존)라 `on delete cascade` 면 자연키가 바뀐 ambiguity 의 decision 이 사라지고 `restrict` 면 replace 가 실패 → update-in-place 또는 soft-delete 로 설계.
- round 2 이력은 review 시 소멸(라벨로만 기능) — decisions 와 함께 이력 정책 결정.
