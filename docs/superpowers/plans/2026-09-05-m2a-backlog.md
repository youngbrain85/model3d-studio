## 2. 코드 백로그 (최종 검토 triage: 백로그)
- `read_sheet` 가 캐시 히트 판정 전에 이미지 전처리(리사이즈·크롭·sha 3회)를 매번 수행 — 대량 재실행 I/O.
- `call_structured`: `stop_reason=max_tokens` 이면 post_validate 위반 목록이 재시도 문구에 실리지 않음; 스키마 stale 캐시는 미스가 아니라 예외.
- read `MAX_TOKENS=8000` 은 고밀도 시트(C04·D02·D04·D07·F01)에서 절단 → 상향은 캐시 키에 포함돼 전량 재과금이므로 전면 재실행 시점에만.
- `review --help` 문구(캐시 미스면 과금), `--budget-usd` 누적 상한, usage.jsonl cached 행 누적, `_pages_map` 중복 I/O, `has_review_rows` 계열마다 새 커넥션, `_save_review` 초 단위 백업 스탬프, `failed_regions` 첫 글자 판정, `_tokens` 조사 구분자(단어 경계 없음), `db.TABLES` 에 readings/ambiguities 미포함, `store` crosscheck `{expr}` 만 저장(설계 §5 `{expr,result,ok}` 와 불일치), 테스트 `_env` 픽스처가 실제 `.env` 로드(delenv 가드 권장), 상수 복제 단언 테스트 2건.
- (해결 982d5dd) `failed` 카운터 r/a 미구분 → `replace_region` 이 `failed_rows`(kind·item·ord·page_no·reason)를
  돌려주고 경고 로그를 남기며, `read`/`review` CLI 가 미해석 행을 줄로 출력한다.
- 설계 미기록 편차: 표제란 타일 1장(설계 §4-1 2~3장), 회전 도곽 미지원(rot=0 전제), 온도 미적용(Sonnet 5 sampling 400), 녹화 응답 픽스처 대신 수기 JSON.
- 크롭 A/C/D/E/F 51장 육안 미확인(B 8장 + 2장만 확인).

## 3. M2b 설계 메모
- M2b 구현(2026-09-05): `decisions.ambiguity_id` FK `on delete restrict` + `replace_region` 보호 집합(결정 달린 행은 삭제·재삽입 금지)으로 해소. round 2 이력 정책은 그대로(라벨).
- `decisions.ambiguity_id` FK: `replace_region` 이 delete+insert(자연키 일치 시 id 보존)라 `on delete cascade` 면 자연키가 바뀐 ambiguity 의 decision 이 사라지고 `restrict` 면 replace 가 실패 → update-in-place 또는 soft-delete 로 설계.
- round 2 이력은 review 시 소멸(라벨로만 기능) — decisions 와 함께 이력 정책 결정.
